# VNHV homepage mock-ups

Three responsive homepage prototypes for **Trường Việt Ngữ Hùng Vương** (vnhv.org, Houston), built from the September 2026 website audit reconciliation.

| Direction | File | Concept |
|---|---|---|
| A — Evolutionary Refresh | `a-evolutionary.html` | Familiar structure, gold logo, navy instead of black |
| B — Conversion-Focused (recommended) | `b-conversion.html` | Enrol / gala / donate journeys first; bamboo-green primary action |
| C — Bold Modern Rebuild | `c-bold.html` | Editorial Lora type, deep-navy grounds, 40-year timeline |

Open `index.html` (or the GitHub Pages site) to pick a direction. Each page has a **📱 mobile preview** toggle and an interaction-states panel at the bottom. Anything not on the live site is marked `[PLACEHOLDER]`; no testimonials, statistics or awards were invented.

**Palette (school uniform colours):** navy `#1F3A5F` / `#14273F`, bamboo green `#2E7D4F`, logo gold `#E0A400` (accent only), rice paper `#FBFAF7`. No black.

Full plan (three-audit comparison, roadmap, backlog, checklists): [PDF](docs/vnhv-rebuild-plan.pdf) · [Markdown](docs/vnhv-rebuild-plan.md).
